# OhioIoT<a href="https://www.ohioiot.com"><img src="https://www.ohioiot.com/logo_150.jpg" width="40" ></a>

OhioIoT provides an external MQTT broker plus tools that help you build your own IoT system.  Here's where to find things.

- [OhioIoT Firmware SDK](https://github.com/OhioIoT-Firmware): the ESP32 firmware SDK that connects devices to the OhioIoT broker ([Documentation](https://ohioiot.com/docs))
- [OhioIoT GitHub Index](https://github.com/OhioIoT-Examples): code examples that go with the OhioIoT YouTube videos
- [OhioIoT Homepage](https://ohioiot.com)

This org also holds the [Tunnel](https://github.com/OhioIoT/Tunnel) repo from the [Remote SSH to Raspberry Pi with Ngrok](https://www.youtube.com/watch?v=0TA-6QaofE8) video.
